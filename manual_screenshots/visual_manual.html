2 进入工作台

在日历上点击日期，系统自动创建运行并跳转到工作台。

工作台三区域：
📁 输入数据区 — 最上方，上传4类文件
✅ 人工确认区 — 中间，确认AI识别结果
📊 运行摘要区 — 最下方，显示运行元数据
页面顶部有步骤指示器：数据录入 → 人工确认 → 报表预览 → 完成发布，当前步骤会高亮。
⚠️ 如果该日期已发布日报，输入区域会被锁定。需要修改请点击"创建同日修订Run"按钮，然后重新上传所有文件。

3 上传四类源文件

🚫 最重要规则：一个一个上传！
上传完一个文件，等它显示绿色对勾 ✓，再上传下一个。
如果在第一个还在解析时上传第二个，前面那个会被"吃掉"显示为"未上传"！

正确顺序和等待方式：

顺序文件类型格式等待标志
①人员表.xls / .xlsx绿色对勾 ✓
②离职人员报表.xls / .xlsx绿色对勾 ✓
③协议签署 / OA ReleaseExcel 或图片绿色对勾 ✓
④招聘数据Excel 或图片绿色对勾 ✓
💡 图片文件（OA和招聘截图）解析需要30秒~2分钟（AI识别），比Excel慢很多，请耐心等待。
📌 状态标志：
✓ 绿色对勾 = 成功上传并解析
⟳ 转圈动画 = 正在解析中，不要操作
✗ 红色错误 = 失败，需要重新上传
🚫 这些操作会导致上传失败：
• 在解析过程中上传另一个文件 → 前面的被覆盖
• 上传过程中点击浏览器返回按钮
• 上传过程中刷新页面
• 看到一个显示"未上传"就立刻重新上传（后台可能还在解析）

4 人工确认识别结果

如果OA或招聘数据是图片格式上传的，AI识别后需要人工核对确认。

操作流程：
1. 在"人工确认"区域看到 "N项待确认"
2. 点击每个待确认项目，查看AI识别的表格数据
3. 仔细核对数据是否正确
4. 确认无误 → 点击 "确认" 按钮
5. 重复直到显示 "无需确认"
⚠️ 上传完图片不等于完成了！必须点击"确认"。如果不去确认，预览按钮会一直灰色。
📌 如果识别结果不对：点击"替换输入"重新上传，或换成Excel格式（更准确）。

5 预览日报 & 发布

所有文件上传完成 + 所有确认处理完毕 → "预览日报与周报"按钮变亮。

操作流程：
1. 点击 "预览日报与周报"
2. 查看日报39行数据（Row2~Row40）
3. 确认数据与预期一致
4. 如果有"阻断"提示 → 不能发布，联系开发人员
5. 确认无误 → 点击 "发布日报"
📌 发布后日报自动成为次日基线。日历上该日期显示"已发布"。
⚠️ 周报只在每周最后一个工作日（周五）可发布。显示"未到周报日"是正常的。

🔧 常见问题速查

你遇到的问题怎么办
预览按钮灰色点不了检查4个文件全上传了吗？人工确认全完成了吗？
上传图片后显示"未上传"等所有上传完成，刷新页面（F5）。不行就重新上传。
两个图片同时上传，前面的不见了正常现象：后台还在解析，刷新页面即可。不要立刻重新上传。
日报有"阻断"无法发布联系开发人员，告知日期和阻断代码。
想修改已发布的日报点击"创建同日修订Run"，全部重新上传。
页面打不开 / 500错误刷新页面，等一会。多次不行联系开发人员。
确认完还是"等待解析"刷新页面（F5），检查人工确认区。
"X-API-Token错误"联系开发人员处理服务器配置。
🆘 什么时候必须找开发人员：
• 页面打不开（刷新也不行）
• "X-API-Token错误"
• 运行记录一直打不开
• 日报一直有阻断校验
• 系统显示500错误
• 上传文件反复失败，换了文件也不行
