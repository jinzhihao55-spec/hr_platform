## 2. 交付物（3 份）

| 交付物 | 模板文件 | 触发 |
|--------|----------|------|
| **A. 日报** | `员工数增减情况日报_输出模板_仅字段结构.xlsx` | **每天** |
| **B. 周报** | `员工数增减周报_输出模板_仅字段结构.xlsx` | 本周**最后一个工作日** |
| **C. 计算日志** | `计算日志_YYYY-MM-DD.md` | 每次出日报/周报时同步 |

固定 Excel 表格是硬要求；Web 预览不能替代。新列继承上一列样式；空白行 Row23/24/27/28/34/35 保持空白。

日志格式：[`calc_log.md`](calc_log.md)。

---

## 3. 周报触发判定

1. 确定今日日期与星期几。
2. **永远先出日报**。
3. 判断是否「本周最后一个工作日」：
   - 默认窗口 = 周一至周五；
   - 含节假日/调休 → 最后一个工作日 = **节假日前最后一个工作日**（Q14）；
   - 是 → **同时出周报**。
4. 节假日：先自查 → 联网核对国务院安排 → 向用户确认（见 [`question_templates.md`](question_templates.md) §3）。

---

## 4. 结构摘要

**日报**（2 sheet，照定稿）：Sheet1 主表 Row2–40（按日追加日期列，Row25/29/36 为分节日期戳）· 在岗时长固定 8 BU（BU_A–H + 合计，空 BU 也输出，报告日仅在 D1）。  
**周报**（2 sheet）：Sheet2 主体×事业部 · Sheet1 成本中心×项目。

口径：[`daily_rows.md`](daily_rows.md)、[`weekly_report.md`](weekly_report.md)。

---

## 5. 归档

`project/日报/YYYY-MM-DD/`（周报归档到对应周目录）。
