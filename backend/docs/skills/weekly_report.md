# 周报计算口径

> **类型**：Skill · **读者**：AI + Python · **模式**：A + B  
> 主 Skill：[`SKILL_CALC.md`](SKILL_CALC.md) · 触发：[`output_spec.md`](output_spec.md) §3

窗口 = 本周一 ~ 本周最后一个工作日（Q14）。窗口末在职从该报告日的 `employee_snapshots` 重算；窗口内入离职从人员主表和离职流程事实计算。缺少窗口末快照时硬阻断。

---

## Sheet2（主体 × 事业部）

- **事业部** = 优先按事业部编号分组，并按 NINS/NENT/NITL/NMSI/NBJO/NWTS/NWMT/NGOV 输出。
- **在职总数** = 窗口末快照中状态为在职、符合纳入口径且入职日 ≤ 窗口结束日。
- **离职事实** = 人员表 LWD + 离职流程：「审批中/等待审批/经理拒绝」→ **仍算在职**；「审批完成」或人员状态已离职 → 算已离。
- **类型拆分** = 正式 + 实习生 + 劳务；长短期实习合并为「实习生」（Q12）；三者之和 = 在职总数。
- **本周入职** = 窗口内入职归属日人数（纳入口径）；归属日 = `max(hire_date, hire_first_visible)`，与日报 Row2 一致。
- **本周离职** = 窗口内 LWD 且离职事实已生效（同上，非仅看日期）。
- **前三大项目** = 先按已确认项目族归并，再按在职人数降序取三（Q16；平手按项目名）。
- **合计行** = 各列纵向 SUM。

## Sheet1（成本中心 × 项目）

- **项目范围** = 配置中固定的 6 个成本中心×项目族；与 Sheet2 共用同一项目族归并结果。
- **在职人数** = 该成本中心/项目族在职数（同上在职规则）。
- **本周入/离职** = 窗口内人数；离职须流程已生效。

## 发布校验

- 窗口末人员快照必须存在。
- 类型拆分必须等于在职总数。
- 窗口内日报齐全时，周报入职/离职必须分别等于日报 Row2/Row3 合计。
- Sheet1 项目族和顺序必须与配置一致。
