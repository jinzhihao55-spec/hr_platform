## 3.7 预估离职链路（★ 公式链）

- **Row30** = 昨日 Row30 + 今日首次可见且 `计入Row30=是`（LWD 在本月；待补 LWD 仅进 Row5）
- **Row31** = 本月申请 + LWD 在本月 + 流程未拒（含主动/协商一致；输出名单）
- **Row32** = 上月申请 + LWD 在本月 + 主动 + 流程未拒
- **Row33** = Row30 + Row31 + Row32
- **Row19** = Row33

## 3.8 招聘预估入职链路

- **Row37** = Row8（MTD 入职，硬等于）
- **Row38 / Row39**：按动态月份列表头识别，优先读取招聘表合计行。
- 同时执行逐行求和交叉校验；若合计行与逐行求和不一致，按 Q7 **硬阻断**，不得静默取数。
- **Row40** = Row37 + Row38 + Row39
- **Row18** = Row40

## 3.9 在岗时长

固定输出 **8 个 BU 槽位 + 合计**（共 9 行），行数不随当日实际有人的 BU 数变化。

| 字段 | 口径 | 计算方式 |
|------|------|----------|
| **事业部** | `BU_A`…`BU_H` 固定 8 槽 + `合计` | 人员表 `事业部` / `事业部编号` 经 `bu_to_slot` 映射到槽位；编号用于同名消歧；空 BU 仍输出该行 |
| **YTD离职人数** | 该 BU 本年累计离职 | 与 Row3/Row14 **同一离职事实口径**：纳入口径 + `leave_date` 在报告年内且 ≤ 报告日 + 离职流程已生效；空 BU = 0 |
| **平均在职（年）** | 该 BU 离职员工平均年限 | `Σ(离职日期 − 入职日期) / 有效离职人数 / 365`，保留 2 位小数；无有效样本 = null/空 |
| **合计校验** ★ | `Σ(各 BU YTD) = B10 = Sheet1 Row14` | 三者必须相等；失败按 BU 列差异硬阻断 |

补充规则：

- 槽位顺序：`BU_A`、`BU_B`、`BU_C`、`BU_D`、`BU_E`、`BU_F`、`BU_G`、`BU_H`、`合计`。
- 纳入口径与 Row2/Row3/Row14 一致：正式员工、长期实习生、短期实习生、劳务人员。
- `hire_date` 缺失或 `leave_date < hire_date`：仍计入 YTD 离职，但从平均分子/分母剔除，记 `tenure_invalid_dates` **软提示**（不阻断）。
- Row14 是链式累计（昨日 Row14 + 今日 Row3），必须与在岗时长 B10 一致。
